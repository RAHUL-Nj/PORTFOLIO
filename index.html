About

The person behind the findings.

My cybersecurity work is driven by hands-on testing rather than only theory. I enjoy taking an application or security problem apart, understanding how the pieces interact, validating what is actually possible, and documenting the result clearly.

I have reported security vulnerabilities to 200+ companies and organizations, including NASA, HDFC, NPCI, Axis, OpenAI, Zerodha, Indeed, ExpressVPN, Upwork, Maruti Suzuki, Ixigo, and many more.

I mainly work in Web Application Security, API Security, Vulnerability Research, Penetration Testing, OSINT, and Digital Forensics.
